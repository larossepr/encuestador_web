# 🚀 Proyecto AMBI

Este proyecto es un conjunto de herramientas (*toolkit*) en Python.  
Esta version contiene una carpeta **encuestador_web** la cual crea una encuesta (predefinida) en formato web.

Este programa es especializado y no de uso general, es un automatizador de una mundana tarea y mi primer programa util para una funcion real.

---

## 📦 Instalación

### Requisitos
- Python **3.8+**
- Librerías listadas en "requirements.txt"

### Instalación de dependencias
```bash
pip install -r requirements.txt


# Uso
Ejecutar *streamlit run main.py* en la carpeta encuestador_web
