# 🚀 Proyecto AMBI

Este proyecto es un conjunto de herramientas (*toolkit*) en Python.  
Actualmente incluye una carpeta **Encuestador** con un módulo llamado **encuestador_wrd.py**, que genera un tipo de encuesta específica de *Análisis de Interesados* en formato Word.

Este programa es especializado y no de uso general, es un automatizador de una mundana tarea y mi primer programa util para una funcion real.

---

## 📦 Instalación

### Requisitos
- Python **3.8+**
- Librerías listadas en `libraries.txt`

### Instalación de dependencias
```bash
pip install -r libraries.txt


# Uso
Ejecutar el encuestador desde la carpeta raíz del proyecto:
python Encuestador/encuestador_wrd.py
O desde la carpeta Encuestador
python encuestador_wrd.py

# Estructura del proyecto
proyecto_ambi/
├─ Encuestador/
│   ├─ encuestador_wrd.py
│   └─ encuestas/
├─ libraries.txt
└─ try.py
